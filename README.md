This lab successfully demonstrates the critical shift from managing standalone autonomous access points to deploying a scalable, controller based wireless architecture. By configuring both models, it shows the concept used on how a wireless LAN controller uses the split-MAC model and CAPWAP tunneling to centralize network configurations and eliminate the administrative overhead and configuration drift associated with autonomous APs. Furthermore, the end to end integration exercises highlight that wireless and wired domains operate as a single unified system, heavily relying on robust DHCP services for both client access and AP initialization. Ultimately, the lab highlights the vital importance of logical segmentation to isolate guest traffic from internal corporate resources, while highlighting the necessity of moving beyond vulnerable WPA2-PSK protocols toward enterprise grade security standards like WPA3 and 802.1X
